# Triage labels

| Role | GitHub label | Meaning |
| --- | --- | --- |
| needs-triage | needs-triage | A maintainer must evaluate the issue. |
| needs-info | needs-info | More information is required. |
| ready-for-agent | ready-for-agent | The specification is ready for agent implementation. |
| ready-for-human | ready-for-human | Human implementation is required. |
| wontfix | wontfix | The issue will not be implemented. |

When a skill names a triage role, use its mapped GitHub label.
Keep unrelated labels unchanged.
